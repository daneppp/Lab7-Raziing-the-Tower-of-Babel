1. Naming: Use meaningful names (SAM)

Bad: int x; / Button btn1;
Good: int itemCount; / Button saveButton;

2. Capitalization: PascalCase for classes and methods, camelCase for local variables (SAM)

Bad: public class userService { void loadItems() { int ItemCount = 0; } }
Good: public class UserService { void LoadItems() { int itemCount = 0; } }

3. Formatting: 4-space indentation, braces on their own line (SAM)

Bad: if (isValid) { Save(); }
Good:
csharp
  if (isValid)
  {
      Save();
  }

4. Method length: Each method does one job (SAM)

Bad: one OnSaveClicked() that checks the input, saves to the database and updates the screen
Good: OnSaveClicked() calls ValidateInput(), SaveData() and RefreshList()
